# RAG Chatbot from Scratch (Groq + FAISS + FastAPI)

## Goal
This project is built to deeply understand how Retrieval-Augmented Generation (RAG) works from first principles.

## Learning Approach
- Build step-by-step
- One component at a time
- No heavy abstractions initially
- Focus on understanding over speed

## Roadmap

- Day 1: Basic LLM Chatbot (Groq)
- Day 2: Document Processing + Chunking
- Day 3: Embeddings + FAISS Retrieval
- Day 4: Full RAG + FastAPI
- Day 5: Pinecone + Evaluation

## Tech Stack
- Python
- Groq API
- FAISS
- FastAPI
- Sentence Transformers
